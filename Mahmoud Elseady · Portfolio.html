Projects

Bank system network

Cisco Packet Tracer · VLANs · Layer 3 switching

A network for a four-floor bank building. Each floor has its own router and Layer 3 switch, and each department sits in its own VLAN with a dedicated subnet, from management and HR to accounting, customer care, and a server room. Routers connect through small point-to-point links, and every department has a switch, PC, printer, and access point.

The result is twelve separated departments that still share one network, so a problem in one team's VLAN doesn't spill into the others.

Blog Post MVC

Laravel · PHP · MySQL · HTML · CSS · JavaScript · Bootstrap

A blog manager built on the MVC pattern. You can create, view, edit, and delete posts, and every post is linked to the user who wrote it, so the list shows who posted what and when. The post page shows the post itself along with its creator's details.

Smart car rental system

C# · .NET console app · object-oriented design

A console application that runs a rental branch. Customers can be registered with phone and email checks, cars are rented for 14 days, and returns calculate a late fee of 150 EGP per day. The system keeps a rental history per customer.

The focus was clean design: an abstract Vehicle class, Car built on top of it, customers and managers sharing a Human base class, and a common printing interface across the model.
